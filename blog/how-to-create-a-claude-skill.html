What is a Claude skill?

A Claude skill is a saved set of steps that tells Claude how to do a specific job. Think of it as a recipe: write the steps once, and Claude follows them every time. A project gives Claude background. A skill tells Claude how to do the work. The video above builds one from scratch.

How to create a skill in Claude

  1. Open Skills. Click Customize, then Skills. Click Add, top right.
  2. Choose how to make it. You can upload a skill, create one yourself, or have Claude build it with you. In the video we create it ourselves.
  3. Name it and describe it. Our example is called visit follow up. The description: turns my customer visit notes into a short follow-up email in our voice.
  4. Write the steps. Keep them numbered and specific. Then click Create.

An example skill: visit follow-up email

These are the steps from the video:

  1. Read my visit notes.
  2. Pull account history from the Northeast Sales project.
  3. Write a follow-up under 120 words that thanks them, recaps next steps, and proposes a call.
  4. Only use claims from the approved product sheet.

Once saved, the skill is switched on. You can edit it, or test it with Try in chat.

How to use a Claude skill

Start a new chat and type a slash. Pick your skill from the list, paste your visit notes, and ask Claude to draft the follow-up. Claude loads the skill and the email comes back in your format, short and following your steps. Claude can also pick up a skill on its own when your request matches it.

Tip: if a skill pulls from a project, like step two above, start the chat inside that project so Claude has the history to work with.

Frequently asked questions

What is a Claude skill?

A Claude skill is a saved set of steps that tells Claude how to do a specific job, like a recipe. You write the steps once and Claude follows them every time you use it.

How do I create a skill in Claude?

Click Customize, then Skills, then Add. Choose to upload a skill, create one yourself, or have Claude build it with you. Give it a name, a description and numbered steps, then click Create.

How do I use a skill in a Claude chat?

Start a new chat and type a slash, then pick your skill from the list. Claude can also pick up a skill on its own when your request matches it.

What is the difference between a Claude project and a skill?

A project gives Claude background, like files and rules for an account. A skill tells Claude how to do a specific job, step by step. They work well together.

Can I test a Claude skill before using it?

Yes. After you create a skill, you can edit it or test it with Try in chat.
