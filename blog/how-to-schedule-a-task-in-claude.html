How to Schedule a Task in Claude

A scheduled task is a prompt Claude runs on its own, at a time you choose. Here is how to set one up in Claude, test it first, and pause it anytime.

What is a scheduled task in Claude?

A scheduled task is like a skill that runs on its own, at a time you choose. You give Claude the instructions and a schedule, and it does the job without you opening a chat. The short video above sets one up from start to finish.

Test the prompt first

Before you schedule anything, run the prompt once by hand. In the video we ask Claude: Summarize my unread emails from distributors, and list what needs a reply. If the result looks right, the prompt is ready to schedule.

How to schedule a task in Claude

  1. Open Scheduled. Click Scheduled in the sidebar, then New task.
  2. Choose Set up manually. You can also choose Create with Claude, covered below.
  3. Name the task and paste your instructions. Use the same prompt you just tested.
  4. Choose how often. Pick hourly, daily, weekdays, weekly or monthly. In the video we use weekly, Monday, 8 AM.
  5. Click Save. The task shows up in your list.

Open the task to see its next run time, and use the switch to pause it anytime. It runs in the cloud, so it keeps going even when your computer is off.

Skip the form with Create with Claude

Do not want to fill out a form? Choose Create with Claude instead and describe the schedule in plain words, like every Monday at 8 AM, summarize my unread distributor emails.

What should you schedule?

If you see Scheduled in your sidebar, you have this feature. A simple rule: if you do the same thing on the same day every week, schedule it. Weekly inbox summaries, Monday pipeline reviews and month-end recaps are good places to start.

Frequently asked questions

What is a scheduled task in Claude?

A scheduled task is a prompt Claude runs on its own at a time you choose, like a skill that runs by itself. You set the instructions and the schedule once.

How do I schedule a task in Claude?

Click Scheduled in the sidebar, then New task. Choose Set up manually, name the task, paste your instructions, pick how often it runs, and click Save.

How often can a Claude scheduled task run?

You can choose hourly, daily, weekdays, weekly or monthly, and pick the day and time.

Do Claude scheduled tasks run when my computer is off?

Yes. Scheduled tasks run in the cloud, so they keep going even when your computer is off. You can pause a task anytime with its switch.

Can I set up a scheduled task without filling out the form?

Yes. Choose Create with Claude and describe the schedule in plain words, and Claude sets it up for you.
