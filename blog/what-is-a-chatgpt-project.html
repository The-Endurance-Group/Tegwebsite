What Is a ChatGPT Project? How to Make One

A ChatGPT project keeps your chats, files and instructions in one place. Here is what projects are and how to create one, with a video walkthrough.

October 6, 2026 · The Endurance Group

What is a ChatGPT project?

A ChatGPT project is a workspace that keeps related chats, files and instructions together. Instead of starting every conversation from zero, you open the project and ChatGPT already knows the background. The video above walks through how to make one. The steps are below.

Why use a project instead of a regular chat

A regular chat only knows what you tell it in that conversation. If you come back tomorrow, you explain everything again. A project holds the context for you:

  • Instructions you write once apply to every chat in the project
  • Files you upload stay available to every chat in the project
  • Related conversations live in one place, not scattered down the sidebar

How to create a ChatGPT project

  1. Open Projects. Find Projects in the ChatGPT sidebar and choose the option to create a new one.
  2. Name it. Use something specific, like a client name or the goal of the work.
  3. Add instructions. Tell ChatGPT who you are, what the project is for, and how you want answers written.
  4. Upload files. Add the reference material the work depends on, such as documents, notes or examples.
  5. Start a chat inside it. Every new conversation in the project now uses your instructions and files.

What to put in a project

Think about what you keep re-explaining. That is what belongs in the instructions. Reference files the work depends on, like a style guide, a price list or a past example you liked, belong in the uploads. The more specific both are, the less you repeat yourself.

Good uses for projects

Projects fit anything ongoing: a client account, a job search, a class, a weekly report, a home renovation or a trip. If you find yourself opening ChatGPT for the same subject again and again, make it a project.

Frequently asked questions

What is a ChatGPT project?

A ChatGPT project is a workspace that groups related chats, uploaded files and custom instructions in one place, so ChatGPT keeps the same context every time you open a new conversation inside it.

How do I create a project in ChatGPT?

Open the sidebar, choose Projects, and select the option to create a new project. Give it a name, add instructions and any files, then start a chat inside it.

What is the difference between a ChatGPT project and a regular chat?

A regular chat starts from scratch. A project remembers its instructions and files across every chat inside it, so you don't have to re-explain the background each time.

What should I put in a ChatGPT project?

Add the instructions you would otherwise repeat, such as your role, tone and goals, plus the reference files the work depends on, like a style guide, price list or past examples.

What are good uses for ChatGPT projects?

Projects work well for anything ongoing: a client account, a job search, a class, a recurring report, or a home or travel plan.
