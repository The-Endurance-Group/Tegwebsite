How to Create a Claude Project (and Stop Re-Pasting Context)

A Claude project holds your instructions and files so every chat already knows the background. Here is how to create one, with a video walkthrough.

What is a Claude project?

A Claude project is a workspace that holds your instructions and reference files, so every chat inside it already knows the background. If you keep pasting the same context into chat after chat, a project fixes that. Put it in once, and every chat in the project starts with it. The video above shows the whole setup.

How to create a Claude project

  1. Open Projects. In the sidebar, click Projects, then New project.
  2. Name it. Use something your team recognizes. In the video we use Northeast Sales Demo. Then click Create project.
  3. Add instructions. Click Add next to Instructions and type the rules once. For example: keep answers short, and only use claims from the product sheet. Click Save instructions.
  4. Add context. Click Add next to Context. You can upload from your device, add text, or connect an app like Google Drive. In the video we upload a product sheet.
  5. Start a chat inside the project. Ask your question. Claude already knows the files and the rules, with nothing uploaded in that chat.

Instructions vs context

Instructions are the rules: how you want answers written and what Claude should or should not do. Context is the material: product sheets, price lists, past examples, account notes. Both are private to you, and both apply to every chat you start in the project.

When to make a project

Make a project for anything you come back to: a sales territory, a client account, a recurring report or a product line. Chats live with the project, so the work stays organized instead of scattered down your recent chats. Not sure whether you need a project or a skill? Read Claude projects vs skills.

Frequently asked questions

What is a Claude project?

A Claude project is a workspace that holds instructions and reference files, so every chat you start inside it already knows the background. You set it up once instead of pasting the same context into every chat.

How do I create a project in Claude?

In the sidebar, click Projects, then New project. Name it, click Create project, then add Instructions and Context. Start a chat inside the project to use it.

What is the difference between instructions and context in a Claude project?

Instructions are the rules Claude follows, like keep answers short. Context is the reference material, like a product sheet or price list, uploaded from your device, added as text, or connected from an app like Google Drive.

Are Claude project instructions and files private?

Yes. In the project setup shown in the video, both Instructions and Context are private to you.

When should I use a Claude project?

Use a project for recurring work you come back to, like a sales territory, client account or regular report, so every chat starts with the same background.
